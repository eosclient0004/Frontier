Projects save layers, decals, masks and material values as .texpaint JSON. Export PNGs per channel — or a packed ORM map — from the Material tab. Double-click a layer to rename it. Drag layers to reorder. Decal layers expose SVG source and typography without rasterizing. If WebGL is blocked, the 3D view falls back to WebGL1 or a software renderer automatically.
